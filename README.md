# Northwind Traders – Power BI Dashboard

This project uses the **Northwind Traders** dataset, a sample business database containing information about customers, products, orders, employees, categories, and shipping.

The dashboard was created in **Power BI** to analyze sales performance, customer and product activity, order fulfillment, shipping, and employee performance through interactive visualizations and KPIs.

## Tools
- Power BI
- DAX
- Power Query
